# 5. Sumber resmi dan catatan verifikasi

[Kembali ke awal](../README.md)

**Tanggal peninjauan: 8 November 2026.** Daftar ini memisahkan dokumentasi produk, materi pelatihan, ketentuan penawaran, dan berita. Penjelasan workshop ditulis ulang; tidak merupakan salinan lengkap atau pengganti dokumen resmi.

## Cara menggunakan sumber

1. Untuk **fitur dan cara penggunaan**, baca Microsoft Learn/Support.
2. Untuk **lisensi, usia, biaya, dan eligibility**, baca ketentuan produk/penawaran serta aturan institusi.
3. Untuk **contoh dampak**, baca berita Microsoft; berita tidak membuktikan ketersediaan umum atau validasi medis.
4. Untuk **pendaftaran program**, gunakan halaman program aktif dan official rules.
5. Periksa tanggal dan apakah halaman membahas akun personal atau organisasi.

## R01 AI Fluency

- **Sumber:** [Microsoft Learn - AI Fluency](https://learn.microsoft.com/en-us/training/paths/ai-fluency/)
- **Jenis:** learning path.
- **Dipakai untuk:** konsep dasar AI, generative AI, prompting, responsible AI, dan peta belajar pemula.
- **Ditinjau:** tujuh modul. Jumlah modul dan isi dapat berubah.

## R02 AI for educators

- **Sumber:** [Microsoft Learn - AI for educators](https://learn.microsoft.com/en-us/training/paths/ai-education/)
- **Jenis:** learning path untuk pendidik.
- **Dipakai untuk:** penerapan AI di kelas, prompt, keselamatan, dan pengembangan guru.
- **Ditinjau:** empat modul; fitur produk yang dibahas tetap mengikuti akses/lisensi masing-masing.

## R03 Get started with Microsoft Copilot

- **Sumber:** [Microsoft Learn - Get started with Microsoft Copilot](https://learn.microsoft.com/en-us/training/modules/get-started-with-copilot/)
- **Jenis:** modul pelatihan.
- **Dipakai untuk:** pengenalan Copilot, model bahasa, interaksi, dan evaluasi hasil.

## R04 Akun dan navigasi

- **Sumber:** [Microsoft Learn - Navigating Copilot: Setup and account types](https://learn.microsoft.com/en-us/training/modules/get-started-with-copilot/3-navigating-copilot-setup-account-types)

- **Dipakai untuk:** masuk dengan akun pribadi, opsi dasar gratis, perbedaan akun kerja/sekolah, dan kolom chat.

## R05 Panduan menulis prompt

- **Sumber:** [Microsoft Support - Get started writing prompts in Microsoft 365 Copilot](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-writing-prompts-in-microsoft-365-copilot)

- **Catatan:** halaman yang ditinjau menjelaskan cakupan beberapa pengalaman Copilot. Contoh dengan email/file organisasi tidak berarti akun personal memperoleh akses ke data kerja.

## Catatan hubungan dengan presentasi

| Materi slide | Perlakuan dalam panduan |
|---|---|
| Timeline AI | Tonggak ilustratif, bukan tanggal penemuan bidang |
| Wave adopsi dan AGI | Konseptual, bukan prediksi pasti atau pernyataan AGI sudah tersedia |
| More > Learn | Bersyarat; chat menjadi alternatif yang tidak mengandalkan menu ini |
| Materi guru "dalam 5 menit" | Draf dapat cepat dibuat; pemeriksaan guru tetap perlu waktu |
| Program gratis | Selalu dipisahkan dari kuota, eligibility, lisensi tambahan, dan biaya ujian |
| Kasus aksesibilitas | Inspirasi yang bersumber dari berita, bukan diagnosis atau validasi klinis |

**Yang diverifikasi untuk paket ini:** isi presentasi dibaca, PDF diekspor dan diperiksa jumlah halamannya, sumber utama dibuka, serta tautan internal diperiksa. **Yang tidak diklaim:** setiap prompt dijalankan pada akun peserta, seluruh menu tersedia pada semua akun, atau agent sudah dibuat di tenant sekolah.
